BRUSH STROKES BY SHENIII — FREE WEBSITE

This folder contains a complete responsive artist portfolio website.

FASTEST FREE WAY TO PUBLISH:
1. Create a free account at GitHub.
2. Create a new PUBLIC repository, e.g. brush-strokes-by-sheniii.
3. Upload index.html and the entire images folder.
4. In the repository, open Settings → Pages.
5. Choose Deploy from a branch → main → / (root) → Save.
6. GitHub will give you a free website address.
